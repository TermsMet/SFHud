# Keybinds

[← Back to README](../README.md)

These are the default shortcuts. You can rebind every action under **Overlay → Keybinds**.

## Overlay

| Key | Action |
|---|---|
| **Alt+~** | Customize mode: drag, resize, restyle, add elements, manage pages, crosshair, DEFCON, music |
| **Ctrl+Alt+H** | Show / hide the overlay |
| **Ctrl+Alt+Backspace** | Hide everything instantly |
| **Ctrl+Alt+]** / **Ctrl+Alt+[** | Next / previous overlay page |

## Notes

| Key | Action |
|---|---|
| **Ctrl+Alt+N** | Quick note into the current pad (Tab switches pad) |
| **Ctrl+Alt+J** | Open the note pads window |
| **Ctrl+Alt+V** | Paste the clipboard as a note |
| **Ctrl+S** | Save now |
| **Ctrl+F** | Global search (in the SFHud window) |

## Timers

| Key | Action |
|---|---|
| **Ctrl+T** | Quick timer |
| **Ctrl+Alt+T** | Type a timer (`7m30s patrol`, `@21:30 event`, `every 10m patrol`) |

## DEFCON

| Key | Action |
|---|---|
| **Ctrl+Alt+PgUp** / **Ctrl+Alt+PgDn** | DEFCON up / down |
| **Ctrl+Alt+Y** | Accept the suggested level |

## Music & window

| Key | Action |
|---|---|
| **Ctrl+Alt+Space** | Music play / pause |
| **Ctrl+Alt+M** | Show / hide the music player |
| **Ctrl+Alt+K** | Open the SFHud window |

## Rebinding

- You can add a key **per pad** (open it or add a note), **per page**, **per DEFCON level**, **per element** and **per timer preset**.
- Duplicate keys, and combos another app already owns, are flagged.
- **In-game only** keys (Ctrl+T, for example) stay free for other apps whenever the game isn't in front.
